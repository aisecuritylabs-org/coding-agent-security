# Security policy

## Reporting a vulnerability

If you find a security problem in the audit containers, the hooks, the example configuration or the guides, email **[info@aisecuritylabs.org](mailto:info@aisecuritylabs.org)** rather than opening a public issue. Include what you found, how to reproduce it, and the affected files or check IDs.

We'll acknowledge your report as soon as we can, and credit you when the fix is published unless you'd rather stay anonymous.

## Scope

This repository contains examples and tools provided as is, with no guarantee of a vulnerability-free setup. Problems in Claude Code, OpenAI Codex or other vendors' products belong with those vendors' own security programmes.
