# Real attacks on AI coding agents, and which audit check covers them

The audit's checks come from attacks that researchers have documented, and in one case that attackers have already used. This page summarises them, with a source for every claim. Figures are as reported by the cited source and were checked against it in September 2026.

## Why CVE feeds are not enough

Adversa AI reviewed ten documented attacks on Claude Code between September 2025 and September 2026: **one ran in the wild against 73 Microsoft repositories, two produced CVEs, and four carry a vendor declination on the record** ([Adversa AI, Sep 23, 2026](https://adversa.ai/blog/claude-code-vulnerabilities/)). A risk register fed only from CVE feeds would miss most of them. "Declined, working as intended" is no less exploitable than a CVE; it is only less tracked.

## Lessons that shaped the audit

- **Opening a repository is an execution event.** Miasma, TrustFall and the trust-dialog CVEs all fire before you type a prompt. Inspect `.claude/`, `.mcp.json`, `CLAUDE.md` and symlinks first (or run the audit on the folder) and open unknown repositories only in a container or VM.
- **Approval prompts are not an integrity control.** SymJack and GhostApproval show a prompt can name one file while the write lands on another. That's why `protect-files.sh` resolves symlinks and judges the *real* target, and blocks writes outside the project.
- **Channel trust is not content trust.** Agentjacking and ToolLeak arrive through a trusted MCP server carrying attacker-written content. Treat MCP output like an HTTP response body.
- **Install-time checks need re-checking at run time.** Plugin4Shell (pinning) and SkillCloak (static scanners) both defeated checks made at install time. Keep auto-updated components on trusted hosts, and don't rely on a scanner alone for skills.
- **Organisations can close what individuals can't.** Managed settings `allowManagedHooksOnly` and `allowManagedMcpServersOnly` stop repository-supplied hooks and MCP servers from running at all ([settings reference](https://code.claude.com/docs/en/settings-reference)).
